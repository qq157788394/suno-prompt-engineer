# 硬性规则清单（质检专家专用知识）

本文件是**硬性规则**——只判格式壳是否合规，不判艺术质量。质检专家据此逐条勾检，输出通过/不通过。

> 本技能定义的是「高质量提示词的最低可行结构（floor）」，不是天花板。凡不在本清单内的，一律不算违规。

---

## A. Styles 提示词规则

- [ ] **A1 · 字符上限**：Styles 总字符数 **≤1000**（含空格与标点，不含 `// 中文参考说明` 注释）。超限即不通过。
- [ ] **A2 · 四段法结构**：必须包含最前端 Genre 描述行 + 三个大写前缀段 `VOCAL:` / `ARRANGEMENT:` / `PRODUCTION:`。缺任意一段即不通过。
- [ ] **A3 · 语言**：全英文主体。中文仅限 `// 中文参考说明` 注释。
- [ ] **A4 · 原创标注**：若为原创曲，须注明 `Tempo is X BPM in the key of Y`。
- [ ] **A5 · 文本解析**：长句用 `and` / `with` 或句号断开，避免逗号连接复合指令。控制信息不引号、不大写喊话。

## B. Lyrics 提示词规则

- [ ] **B1 · 属性列表格式**：每段 `[Key: Value]` 英文属性行，写在歌词上方、中间不留空行。段落间空一行。
- [ ] **B2 · 无中文控制信息**：所有控制信息用英文。圆括号 `()` 仅用于歌词内注解。
- [ ] **B3 · 每段有动态标记**：有声乐段落须有 `[Dynamics:]`（力度记号 pp/p/mp/mf/f/ff/fff）。
- [ ] **B4 · 无词段不写 Vocal**：前奏/间奏/尾奏等器乐段不写 `[Vocal:]`。
- [ ] **B5 · 属性精炼**：每段只写关键特征，无明显无关堆砌。Instrument 行不超过 3 个元素。
- [ ] **B6 · 声部分类不重复**：单一声部歌曲中，声部分类/性别（tenor/soprano/male/female 等）已在 Styles 的 VOCAL 段定义，Lyrics 各段的 Vocal 行不重复声明。对唱/duet 歌曲中，段间声部切换标注不受此限
- [ ] **B7 · 无和声概念标签**：不使用 Neapolitan、chromatic progression 等音乐理论术语。用声学物理描述替代（如 chromatic slides、dissonant stacks）。
- [ ] **B8 · 无人名/乐队名**：不出现 David Bowie、Nirvana 等人名或乐队名引用。技法特征须拆解为具体术语。
- [ ] **B9 · 同曲 key 命名一致**：同一首歌内段落标签与属性 key 命名统一。

## C. 通用

- [ ] **C1 · 模板不带歌词**（仅开发模板场景）：Lyrics 中所有有声乐段须使用歌词占位（如 `(填入主歌1歌词)`），不包含实际歌词。
- [ ] **C2 · 模板套用一致性**（仅套模板场景）：Styles 结构须与对标模板一致，用户原词段落须保留。

---

## 通过 / 不通过 判定

- A1–A5、B1–B9、C1–C2 全部通过 → **通过**
- 任一硬规则未过 → **不通过**，列出违规项 + 修改指向（指向对应专家）
- B5 为提醒级：不强制判不通过，但须在结论中标注
