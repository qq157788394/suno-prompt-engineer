# 创意维度选词表（Creative Dimension Vocabulary）

> 把"模糊感觉"翻译成 Suno 能读的英文设定时，从这里挑词。

**归类方式**：按本技能的核心五控制面（Vocal / Dynamics / Instrument / Texture / Mood）组织，方便你对着维度快速取词。

**来源署名**：词汇灵感来自 **Noema Lab《提示词教学》"创作坐标系"**（公众号公开发表，知识类内容，可自由学习）；此处按 Suno 提示词写作习惯重新组织，并非照搬原框架。

**用法**：不是每个维度都要写。按 SKILL.md「需求翻译四步」挑对这首歌重要的维度取词即可——维度是"思考透镜"不是"必填项"。

---
